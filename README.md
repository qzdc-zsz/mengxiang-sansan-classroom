# 洛克王国世界计算器｜梦想三三小课堂

**洛克王国世界计算器**，面向《洛克王国：世界》玩家，提供精灵图鉴、技能图鉴、技能伤害计算、属性克制查询、队伍规划和实战辅助。可搜索“洛克王国世界伤害计算器”“洛克王国世界精灵图鉴”“洛克王国世界技能图鉴”快速找到本项目。

梦想三三小课堂提供 Windows 安装版，普通玩家无需命令行即可使用。计算结果用于参考，游戏版本、特性和战斗状态可能影响实际伤害。

## 主要功能

- **精灵图鉴**：收录 499 条精灵形态资料，可按名称、编号、属性、蛋组筛选并翻页查看。
- **技能图鉴**：收录 480 条技能资料，支持属性筛选、搜索，并查看技能效果及可学习精灵。
- **伤害计算器**：自定义精灵个体、性格、属性、技能、能力等级、增益减益、天气和倍率，查看伤害估算与克制关系。
- **属性关系**：查询单属性或双属性的克制、抵抗、双倍及多倍关系。
- **队伍规划**：配置最多六只精灵及各自技能，查看属性覆盖、共同弱点和联防抗性。
- **精灵蛋鉴定**：按蛋的身高和体重查询候选精灵及大块头、小不点提示。
- **实战悬浮窗**：辅助识别游戏画面中的精灵和技能，并结合技能池与战斗信息提供伤害估算。识别结果可以手动修正。

图鉴数据来自社区公开资料与 Wiki 镜像，数据覆盖范围和计算规则以应用内说明为准；内容可能随游戏更新而变化。
